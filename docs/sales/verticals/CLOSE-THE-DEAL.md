## B. Qualification (before you demo)

Must answer **yes** to enough of these:

1. Decision-maker or influencer on the call (owner / admin / director)  
2. Clear pain (billing, appointments, fees, kitchen orders, etc.)  
3. Timeline &lt; 90 days **or** budget discussion allowed  
4. Fits product (not asking for OTT/taxi build as Phase-1)  
5. Can pay ≥ floor package (soft signal)

**Disqualify fast:** “Send free full source + free 6 months support”, students, tire-kickers wanting 20 custom modules at ₹50k.

## C. Demo → close sequence (timings)

| Step | When | Action |
|---|---|---|
| Book | On qualify | Calendar invite + “join 5 min early” |
| Remind | T−3h | WhatsApp reminder + product page link |
| Demo | 10–12 min | Vertical demo script only |
| Soft close | Last 2 min | “Shall I send proposal with package + AMC by tomorrow?” |
| Proposal | ≤ **24h** | PDF + payment milestone terms |
| Follow-up | Day 2, 5, 10 | Scripted; offer to adjust Phase-1 scope not random discount |
| Negotiate | As needed | Trade scope for price; never silent cut |
| Close | Verbal/WA accept | Kickoff invoice **40%** |
| Lock | Payment cleared | Kickoff call + asset checklist |
| Expand | Day 30 / 90 | Marketing retainer + second branch |

## D. Commercial close rules

| Rule | Detail |
|---|---|
| Floors | Clinic ₹1.5L · Hospital ₹3.5L · School ₹1.5L · Restaurant ₹1.5L |
| Payment | 40% / 40% / 20% |
| AMC | Mandatory on every software win (or written decline + higher one-time) |
| Discount max | 10% only for annual AMC prepaid or multi-branch — founder approval |
| Validity | Proposal 14 days |
| Change requests | Outside package hours = paid |

## E. Documents to send (order)

1. One-pager (optional before demo)  
2. After demo: **Proposal PDF**  
3. On accept: **Invoice + MSA/SoW**  
4. On kickoff: Asset checklist (logo, domain, gateway keys)  
5. At go-live: AMC start + support hours

## F. Objection → close lines (universal)

| Objection | Response |
|---|---|
| “Send brochure only” | “Brochure won’t show billing flow — 12-min live demo does. Tue 3pm or Wed 11am?” |
| “Too costly” | “We can Phase-1 core modules at Starter; add pharmacy/apps later.” |
| “Need free trial 3 months” | “Live demo now + staging UAT after kickoff for 1–2 weeks.” |
| “Other vendor cheaper” | “Compare inclusions: white-label, training, go-live, AMC. I’ll itemize.” |
| “Call next year” | “Noted — I’ll check in `[month]`. Demo link stays live.” |
| “Source code?” | “License options in proposal — data always yours.” |

## G. Won definition

Deal is **Won** only when **kickoff payment is in the bank** (not verbal yes).
