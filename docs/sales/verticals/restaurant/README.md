# Vertical 4 — Restaurants (FoodKing)

**Priority:** #2 for evening outreach  
**Product:** FoodKing  
**Ticket:** ₹1.5L–₹5L + AMC ₹15–30k/mo  
**Cycle:** 5–20 days (owners decide fast if pain is live)

## ICP
- Independent restaurants, café/QSR, cloud kitchens, small multi-branch  
- Pain: WhatsApp orders ≠ kitchen, no POS/KDS sync, delivery chaos  
- Buyer: owner / operating partner (often evenings)

## Avoid early
- “Build Swiggy competitor for whole city” — that’s marketplace; sell **their restaurant stack**  
- Pure franchise RFPs needing 6 apps before payment
