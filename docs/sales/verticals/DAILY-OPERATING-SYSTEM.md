# Daily operating system — 4 verticals

**Assumption:** Solo founder, ~9–10 focused hours/day, 5–6 days/week.  
**Rule:** Protect demo and close blocks. Outreach fills the rest.

---

## Recommended day (Mon–Fri) — 9.5 hours

| Block | Time (IST) | Duration | Where / tools | What you do |
|---|---|---|---|---|
| **0. Demo health** | 09:00–09:15 | 15m | Browser | Open all 4 login URLs; fix/block if broken |
| **1. Inbound + RFQ** | 09:15–10:00 | 45m | IndiaMART + WhatsApp + site forms | Reply every warm lead (&lt;15 min standard) |
| **2. Outreach A — Clinics** | 10:00–11:15 | 75m | Google Maps + WA Business | 25 new clinic messages (Pune → nearby) |
| **3. Outreach B — rotate** | 11:15–12:15 | 60m | Maps / LinkedIn / IndiaMART | **Day rotate** (see below) |
| **4. Follow-ups** | 12:15–13:00 | 45m | CRM sheet + WA | Day+2 / +5 / +10 sequences |
| Lunch | 13:00–13:45 | 45m | — | Off phone |
| **5. Demos / discovery calls** | 13:45–16:15 | 150m | Meet / Zoom / WA video | 1–3 booked demos; buffer for slip |
| **6. Proposals + close** | 16:15–17:30 | 75m | Docs + PDF + CRM | Same-day proposals; negotiate |
| **7. Outreach C — evening vertical** | 17:30–18:45 | 75m | Maps + WA | Restaurants (owners free) **or** schools (admin hours) |
| **8. Pipeline + AI batch** | 18:45–19:15 | 30m | Sheet + ChatGPT/Claude | Log next actions; queue tomorrow’s 50 drafts |
| **9. Optional delivery** | 19:15–20:15 | 60m | Only if paid project live | Config / client WhatsApp — **cap at 1h** until you hire |

**Saturday (half day, 4h):** IndiaMART clean-up + 40 follow-ups + 1 demo slot + record 1 demo video.  
**Sunday:** Off or 1h content (1 Reel per vertical/week).

---

## Day rotate for Block 3 (60 min)

| Weekday | Vertical focus | Channel mix |
|---|---|---|
| Mon | **Hospitals** | Maps nursing homes + LinkedIn admins |
| Tue | **Schools / coaching** | Maps schools + IndiaMART school ERP |
| Wed | **Hospitals** | Tier-2 cities WhatsApp |
| Thu | **Schools** | Coaching institutes (exam season push) |
| Fri | **Restaurants** (prep list) + partner CAs | Partner messages |

Clinics are **every day** in Block 2 (highest volume).  
Restaurants get **evening Block 7** (owners answer after lunch rush / evening).

## Time budget by vertical (per week)

| Vertical | Hours/week | % | Rationale |
|---|---|---|---|
| Clinics | **10h** | 28% | Primary volume + fastest close |
| Restaurants | **7h** | 20% | Evening outreach + local density |
| Schools | **6.5h** | 18% | IndiaMART + admin-hour calls |
| Hospitals | **6.5h** | 18% | Fewer leads, longer demos |
| Shared (inbound, proposals, CRM, demos prep) | **5.5h** | 16% | Closes all verticals |
| **Total** | **~35.5h** | 100% | Core sales week |

Delivery for paid work is **extra** — hire at 2 concurrent projects.

## Energy rules

- Never demo before 09:15 health check.  
- Never write proposals after 21:00 (error rate up).  
- If zero demos booked by Wednesday, cut partner time and double clinic Maps.  
- If &gt;3 open proposals, stop new cold outreach Thursday–Friday and only follow-up/close.
