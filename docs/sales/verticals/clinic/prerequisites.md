# Clinic deal — prerequisites & qualify

## Before pitching this lead
- [ ] CareDesk login works today  
- [ ] One-pager PDF ready to send  
- [ ] Know Starter vs Growth recommendation  

## Qualify on first reply / call
1. Specialty + city  
2. Doctors count + reception staff  
3. Branches  
4. Current tool (paper / Excel / Practo / other)  
5. Must-have: online booking? WhatsApp? GST bills?  
6. Who signs?  
7. Go-live urgency  

## Fit
- **CareDesk** if OPD/appointments primary  
- Switch to **HospitalOS** if IPD/wards/pharmacy/lab heavy  

## Assets needed from client at kickoff
Logo, domain, doctor list, service price list, Razorpay/Cashfree KYC, SMS/WhatsApp provider keys, GST details
