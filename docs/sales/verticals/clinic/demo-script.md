# CareDesk demo script (10–12 min)

## Open (1 min)
> “I’ll show booking → doctor note → bill. Stop me if a screen doesn’t match your clinic.”

Confirm: multi-doctor? branches? patient app interest?

## Walkthrough
| Min | Show | Say |
|---|---|---|
| 1–2 | Admin login | “Your branded operations console.” |
| 2–4 | Appointment calendar | Book a slot; multi-doctor. “Kills double-booking.” |
| 4–6 | Doctor encounter + Rx | “Doctor finishes in one place.” |
| 6–8 | Billing / invoice | “Front desk closes cash same visit.” |
| 8–9 | Patient booking (optional) | “Website/app booking + reminders.” |
| 9–10 | Roles | Admin / doctor / reception |

## Close (2 min)
> “For a clinic your size, **CareDesk Starter/Growth** is typically ₹[band] + AMC. Shall I send a written proposal by tomorrow?”

Book follow-up on calendar same day.
