# Clinic outreach scripts (CareDesk)

## Where to find leads
1. Google Maps: `dental clinic [area]`, `polyclinic [area]`, `skin clinic Pune`  
2. Practo / Justdial lists → WhatsApp  
3. IndiaMART: “clinic management software”, “appointment software”  
4. LinkedIn: Clinic Owner, Dental Surgeon (practice owner)  
5. Facebook: local doctors groups (soft value posts)

## First WhatsApp
> Hi Dr. `[Name]`, I’m `[You]` from Nextera Digital Tech (Pune). We help clinics run appointments, prescriptions & billing in one system — live product, not slides.  
> Demo: https://nexteradigitaltech.in/demos/caredesk/  
> Open to a 15-min walkthrough for `[Clinic]` this week?

## Follow-up Day +2
> Quick bump — I can show only booking → prescription → invoice (12 mins). Morning or evening better?

## Follow-up Day +5
> Sharing admin demo login if you want a peek first:  
> https://nexteradigitaltech.in/demos-live/caredesk/admin/login  
> Then we can do a guided call. Worth 15 mins?

## Follow-up Day +10
> Last note — if timing is off, tell me when you revisit clinic software and I’ll check back.  

## LinkedIn connect
> Hi Dr. `[Name]` — we white-label clinic platforms (live demos). Connecting with practice owners in `[city]`.
