# Hospital vertical — pricing packages (internal)

Tune numbers to your delivery cost before external use. Bands below match the one-pager.

## Package matrix

### CareDesk — clinics

| | Starter | Growth | Enterprise / Chain |
|---|---|---|---|

| **License + white-label** | ₹1.5L – ₹2.0L | ₹2.5L – ₹3.5L | ₹4.5L+ |
| **Setup & training** | Included (remote) | Included | Onsite optional |
| **Customization hours** | 20h | 40h | Scoped |
| **Patient + staff apps** | Web portal | Apps included | Apps + CI branding |
| **WhatsApp / SMS** | Client gateway keys | Assisted setup | Multi-number |
| **Timeline** | 3–5 weeks | 5–8 weeks | 8–12 weeks |
| **AMC / month** | ₹15k – ₹20k | ₹25k – ₹35k | ₹40k+ |

## Payment schedule (default)

| Milestone | % |
|---|---|
| Proposal acceptance / kickoff | 40% |
| UAT / staging ready | 40% |
| Go-live | 20% |
| AMC | Monthly or annual (5–10% discount if annual prepaid) |

## Margin guardrails

- Never sell below **2×** estimated delivery cost (people + hosting setup).  
- Every custom “Must” outside package hours → change request rate (suggest ₹2,000–₹3,500/hour or fixed CR).  
- AMC minimum covers cloud + 4h support/month; raise SLA price for 24×7.

## Upsell ladder (recurring)

1. Year-1 AMC  
2. Second branch / second clinic license  
3. Mobile apps (if Starter)  
4. Digital marketing / Google Business / patient acquisition retainer  
5. Security audit + hardening annual  

## Objection → price response

| Objection | Response |
|---|---|
| “Too expensive vs local freelancer” | “You’re buying a running hospital/clinic product + go-live + AMC, not a rebuilt Excel.” |
| “Only want source code, no AMC” | “Source/license options exist; hosting + updates still recommended. Quote separately.” |
| “Can you match XYZ HMS at half price?” | “We can phase modules — Phase-1 OPD+billing, Phase-2 pharmacy/lab.” |
| “Need free trial for 3 months” | “Live demo + 2-week UAT on staging after kickoff payment.” |
