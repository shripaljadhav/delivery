# Hospital demo script (10–12 minutes)

Goal: prospect says “send the proposal” — not a full training session.

## Before the call (2 min)

- Confirm CareDesk vs HospitalOS from discovery answers  
- Open login page + product page in separate tabs  
- Mute notifications; use headphones  
- Have pricing bands ready (do not lead with price)

## Minute 0–1 — Frame

> “I’ll show the live product for [clinic/hospital] workflows — booking/registration, clinical note, and billing. Interrupt anytime if a screen doesn’t match how you work.”

Ask one confirm: “Do you run IPD/wards, or mainly OPD/appointments?”

## Path A — CareDesk (clinic) ~9 min

| Min | Screen | Say / show |
|---|---|---|
| 1–2 | Admin login | Log in as admin. “This is the operations console for your brand.” |
| 2–4 | Appointments / calendar | Book a slot for a doctor. Show multi-doctor schedule. “This replaces phone diary double-booking.” |
| 4–6 | Doctor workspace | Open encounter: symptoms → prescription. “Doctor finishes in one place.” |
| 6–8 | Billing / invoice | Generate invoice for consult + service. “Front desk closes cash same visit.” |
| 8–9 | Patient booking (if time) | Show patient-facing booking. “Optional website/app booking + reminders.” |
| 9–10 | Roles | Mention receptionist / doctor / admin. “Staff only see what they need.” |

## Path B — HospitalOS (hospital) ~10 min

| Min | Screen | Say / show |
|---|---|---|
| 1–2 | Super admin / tenant | Explain multi-hospital tenancy in one sentence. Switch to hospital admin. |
| 2–4 | Patient registry / OPD | Register / open patient. “One ID across desks.” |
| 4–6 | IPD / bed (if they have wards) | Show admission / bed. Skip if pure day-care. |
| 6–8 | Pharmacy or lab | Pick the one they care about. “Linked to the same patient.” |
| 8–10 | Billing / discharge charges | Show charge compilation. “Fewer reconciliation fights between wards and accounts.” |
| 10 | Reports | One report screen if available. “Owner visibility without Excel.” |

## Minute 10–12 — Close

1. Reflect their pain in one line.  
2. Propose package band (Starter / Growth) — not a single rupee yet.  
3. Timeline band.  
4. Ask: “Shall I send a written proposal with scope and AMC by tomorrow?”  
5. Book next step on calendar.

### Soft close lines

- “Most clinics start with CareDesk Growth if they want the patient app.”  
- “Hospitals usually start single-facility HospitalOS, then add branches.”  
- “AMC covers hosting, updates, and support so you’re not orphaned after go-live.”

### Do not

- Demo MediCore  
- Say “Uber/Netflix-style clone” or oversell AI modules unless they ask  
- Promise TPA/LIS/Tally unless scoped  
- Argue features not in the live build — park as “custom line item”
